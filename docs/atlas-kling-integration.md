# Kling 单入口接入

状态：本地实现与测试完成，未发布桌面版本、未部署网关、未执行线上数据库迁移。

模型菜单只增加一个 **Kling**，排在 Seedance 2.5 后。参数框提供 V3 标准、V3 Pro、V3 Turbo、V3 4K、O3 4K 五档；分辨率、时长、首尾帧和声音按所选档位联动。默认标准档、720P、5 秒、无声。SR 与原生分辨率分组显示，窄窗口可滚动。历史素材与重复生成保留版本和声音设置。

| 版本 | 支持的分辨率 | 时长 | 尾帧 / 声音 | 默认分辨率 5 秒积分：无声 / 有声 |
| --- | --- | --- | --- | --- |
| V3 标准 | 720P、1080P-SR、1440P-SR | 5、10 秒 | 支持 | 60 / 88 |
| V3 Pro | 1080P、1440P-SR | 5、10 秒 | 支持 | 79 / 115 |
| V3 Turbo | 720P、1080P | 5、10 秒 | 当前 Schema 无这些字段 | 79 / 不提供开关 |
| V3 4K | 4K | 3–15 秒 | 支持 | 279 / 279 |
| O3 4K | 4K | 3–15 秒 | 支持 | 279 / 279 |

本轮范围为截图标出的五个图生视频入口。Avatar、动作迁移、文生视频、主体元素、自定义多镜头和声音克隆不在本轮范围内。标准/Pro/Turbo 的描述文档列 5/10 秒，Schema 列 3–15 秒；当前仅开放两者共同支持的 5/10 秒。

## 接口与计费证据

2026-09-09 使用现有 Railway AtlasCloud 凭据调用只读报价接口 `POST /api/v1/model/calculate`，分别核对各分辨率和声音状态。使用实时报价的完整数值，不使用商城四舍五入的起价。

- 标准 720P、5 秒：无声 $0.357；有声 $0.5355。
- Turbo 1080P、5 秒：$0.595，而不是按列表 $0.095/秒计算。
- 标准/Pro 的 SR 单独计价；4K 由模型 ID 选择，不能把 Schema 中遗留的 1080P 默认值发送出去。
- 真实标准 720P、5 秒、无声任务 `19fdfe7eccf84008a58e85d2df9d5a8f` 已完成并返回视频，未重复提交。
- Schema 的 `/model/result/{id}` 使用现有密钥返回 401；真实任务返回的 `/model/prediction/{id}` 查询成功。最终实现采用后者。

每次提交前核查实时上游报价；超过已核实成本或无法核价时不创建付费任务。使用现有支付费、运营分摊、汇率和成本缓冲计算积分。当前没有给 Kling 开放跨型号或昂贵备用通道。网关到上游的受理状态不明时不重试另一付费请求。

计费身份包含版本和声音，异步任务 ID 另行保留真实执行提供方 `video-14`，因此数据库记账身份不会导致恢复时查询错误通道。帧图片限制为 PNG/JPEG、最多 10 MB、边长至少 300 px、宽高比 0.4–2.5；本地帧在上传前验证，远程素材仍受上游实际文件验证。

## 发布依赖

先应用 `202609090001_economy_media_pricing.sql` 与 `202609090002_atlas_kling_pricing.sql`，再同步网关目录 61 和桌面。Kling 迁移扩展报价、预留、恢复记账和下载结算的允许清单，并保留服务端调用权限。不要只发客户端或只修改积分表。前一轮全上游经济路由仍有独立未完成事项，本功能不代表该工作全部完成。

Schema / README 来源为 https://www.atlascloud.ai/models/kwaivgi/kling-v3.0-std/image-to-video 及同目录的 `kling-v3.0-pro`、`kling-v3.0-turbo`、`kling-v3.0-4k`、`kling-video-o3-4k` 页面。价格按账号实际报价核验，未来变动由提交前检查拦截。
