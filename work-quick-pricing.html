FAQ

你关心的问题

关于API聚合和QuickRouter.AI使用的常见问题解答。

常见问题解答

免费额度能不能跑通第一次测试？

可以。注册即送免费额度，可用于完成 API 调用测试。例如可以使用 claude-sonnet-4-6 或 gpt-5.4-mini 等模型进行对话测试。

配置失败应该找谁？

如果配置过程中遇到问题，可以通过页面右下角的在线客服随时联系我们，我们的客服团队 7×24 小时在线，会第一时间帮你排查和解决。

Base URL 应该填什么？

大部分工具的 Base URL 填写 https://api.quickrouter.ai/v1 。Claude Code 是特例，填写 https://api.quickrouter.ai（不加 /v1）。具体以各工具配置教程中的说明为准。

Claude Code /Cursor /Codex 等工具怎么配置？

在首页「选择你的开发工具」区域，找到你使用的工具卡片，卡片中会标注 API Key、Base URL、模型名和对应的填写位置。也可以点击「查看详细教程」查看完整的图文步骤。

注册后第一步应该做什么？

注册后，请登录控制台，在「令牌管理」中点击「添加令牌」创建你的 API Key。创建后复制保存，后续在开发工具中需要填入这个 Key。

你们的服务是否兼容 OpenAI 接口协议？

是的，我们的服务完全兼容 OpenAI 接口协议。接入时通常只需替换 API Key 和 Base URL，即可快速完成对接，无需额外改造原有业务代码。

什么是“充值打折，原价计费”？

我们的计费规则与模型官方保持一致，后台价格与模型厂商官方标准 100% 同步。不同之处在于，您在充值时可以享受相应折扣。也就是说，计费仍按官方原价规则执行，但您的实际使用成本会因充值折扣而降低。若您在使用过程中发现任何计费异常，请及时联系我们，我们会第一时间核查并妥善处理，确保退款或补款准确无误。

什么是 API 中转？

API 中转是指通过统一的接口服务，将您的请求转发至对应的模型官方渠道进行处理。这样可以帮助您更方便地接入不同模型服务，减少适配成本，并获得更稳定、统一的调用体验。
